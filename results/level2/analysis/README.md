# Derived tables of the revision

Produced by `scripts/analysis/`. `eqdiv.csv`: for each adapter and weight-space lambda (`lam_w`), the logit-space lambda with the same domain-text KL (`lam_star`) and the perplexity differences logit minus weight on domain text (`d_dom`), on general text with the domain KL axis (`d_gen_domKL`) and with the general KL axis (`d_gen_genKL`), with 95% paired bootstrap intervals. `bench_eq.csv`: mean zero-shot accuracy (LAMBADA, HellaSwag acc_norm, PIQA, ARC-Easy) of both forms at equal general-text KL. `entmatch.csv` / `entci.csv`: DynaLoRA vs the plain adapter at matched mean entropy. `curves_ci.csv`: response-curve intervals. `replication_*.csv`: the same comparisons for all adapters including the seed replicates, Qwen2.5-1.5B, and Qwen2.5-7B (`scripts/analysis/replication.py`). `mauve__gpt2-large__nohtml.csv`: MAUVE of every grid point against the reference continuations, with HTML tags removed from the generations as they are from the references (`scripts/mauve_eval.py --strip_html`, `notebooks/colab_mauve_nohtml.ipynb`); these are the values reported in the paper. `mauve__gpt2-large.csv`: the earlier computation with tags kept in the generations; `human_split` rows give the value between two halves of the reference texts (`run == reference` for the main runs, `reference_qwen7b` for the Qwen2.5-7B run). `fig_frontier.pdf`, `frontier.csv`: domain against general perplexity along lambda (`scripts/analysis/figfrontier.py`).

`reference_format.csv`: corpus formatting rate of the 50-token reference windows with HTML tags kept and removed (`scripts/reference_format.py`).

`pubmedqa_curves.csv`, `pubmedqa_eq.csv` (`scripts/analysis/pubmedqa.py`): downstream accuracy on PubMedQA, all 1,000 expert-labeled questions (PQA-L, yes/no/maybe scored by the log-likelihood of each option, prompt and metric of the lm-evaluation-harness task `pubmedqa`), for the PubMed adapters (GPT-2 with its two seed replicates, Qwen2.5-1.5B, Qwen2.5-7B in 4 bits) and the balanced IMDB adapters as out-of-domain control; per-question scores in `results/level2/pubmedqa/` (`notebooks/colab_pubmedqa.ipynb`). `pubmedqa_curves.csv`: accuracy in % per `model`, `config`, `method` and `lam` with 95% bootstrap interval over questions (`lo`, `hi`), and the paired change from lambda 0 (`d_base`, `d_lo`, `d_hi`); `n` questions. `pubmedqa_eq.csv`: for each weight-space lambda (`lam_w`), the logit-space lambda (`lam_star`) with the same KL divergence from the base model on general text (`kl_set == general`, the matching of `bench_eq.csv`) or on the adapter's domain text (`kl_set == domain`), the two accuracies and their difference logit minus weight (`diff`) with a 95% paired bootstrap interval over questions; `beyond_grid` marks a weight-space KL above the largest logit-space KL of the grid, where `lam_star` is clamped to 3. `pubmedqa_by_answer.csv`: accuracy per gold answer (yes, no, maybe) and the share of questions with each answer, which separates a shift of the answer prior from a change in the reading of the abstract (`--by_answer`; the labels are loaded from the Hub at run time and are not stored here).
